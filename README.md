# Движок скидок (Discount Engine)

Решение практической работы по ООП и паттернам проектирования.

## Архитектура

- **Models** — базовые сущности (Product, CartItem, Customer, Order).
- **Engine** — `PricingEngine` управляет процессом, `DiscountContext` хранит промежуточные суммы.
- **Discounts** — 7 стратегий скидок, реализующих интерфейс `IDiscount`.
- **Factory** — `DiscountFactory` создает скидки по строковому типу, `ConfigProvider` (Синглтон) хранит конфигурацию.

## Порядок применения скидок

1. «3 по цене 2» (считается первым).
2. Процентные скидки. Обычная процентная скидка и процентный промокод сравниваются. Применяется тот, что выгоднее (при равенстве выбирается промокод).
3. Лояльность.
4. Первый заказ.
5. Фиксированные скидки (и фиксированный промокод).
6. Бесплатная доставка (проверяется строгое условие: сумма > порога).

## Округление

Используется банковское округление (`Round half to even`) до копеек. Округление применяется к результату каждой отдельной скидки сразу в момент её применения (в классе `Money`).

## Промокоды

- Сравнение кодов регистронезависимое.
- Дата окончания включительна (если срок истекает сегодня, промокод еще работает).
- Один промокод не может быть применен дважды за один расчет.

## Как запустить

1. Сборка: `dotnet build`
2. Демо-пример: `dotnet run --project DiscountEngine`
3. Тесты: `dotnet test`
